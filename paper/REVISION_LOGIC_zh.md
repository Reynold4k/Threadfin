# 从统计展示到 GC 生物学论证：本轮修改的逻辑

核心变化是先确定实验能回答的问题，再选择克隆统计和图形。我们没有把每个数据集都写成一次成功的命运推断。

最初的叙事围绕“整合、嵌入、聚类、显著性、跨数据集运行”。它证明包可以处理数据，但容易让读者以为 UMAP 上相邻家族是谱系关系，或者聚类分支代表未来命运。现在拆成三个可核验的层次：**同一个 donor 内的受体序列支持家族成员关系；RNA 描述当前状态；不同家族的 profile 相似性描述捕获状态分布的相似性。** 重新聚类得到的是状态相似的家族群，不负责建立家族之间的共同祖先。

第二步是收紧到 GC。NP-OVA/RBD 的实验 reporter 锚定近期分裂和 GC 区室，Plasmodium 锚定同鼠感染中的状态共现，人疫苗锚定同一 donor 的重复 GC 采样。三个实验承担不同问题，不能靠一条跨模型拟时间连接。最强的 non-GC 骨髓纯门验证移到 Supplementary 5；其他弱解释数据保留在 tested_datasets 子目录，跨模型汇总中标为覆盖测试。

第三步是把“克隆解释性”写具体：一张 clone map 应让读者知道一个点是谁、点的颜色对应哪项测量、这个家族包含哪些状态、哪些关系来自同一 BCR 家族、哪些只来自 RNA 相似、哪一步经过了条件对照。Figure 2 因此并列独立测得的 division label 和 BCR mutation load。Figure 2B 按你的报告使用 GSE246382；它与 C/D 的 reporter 数据是不同队列，图注明确区分。这个较小数据集没有足够可靠 profile 支持 programme/fate 分支，也明确报告。

第四步是反查看似漂亮的生物学逻辑。Plasmodium 的每个时间点是不同终末取样的鼠，不能把跨日相似序列当同鼠纵向轨迹。我们保留同鼠 GC–PB 家族实例，再检查 clone size、状态丰度和 isotype 的零模型。观测到共享家族，但没有一致超出同型组成预期的正富集。这使结论从“发现 GC 输出命运分岔”收紧为“识别可复核的共同受体状态和后续实验候选”。早期 memory、GC 再进入和最终 PC 分化仍需要命运追踪或 recall 实验。

第五步是核查图形变化是否来自分析。Figure 3 的早期 801 和晚期 1,183 个家族重跑前后，成员和 UMAP 坐标完全一致；此前视觉上“线性关系消失”是将早期 PB 视图换成晚期 GC 视图，并改变点大小和比例。现在两个队列并排，另附复现审计，不为了恢复形状重新调 embedding。Spike 的结合标签和 SHM 也分别解释，不能将任意一条 SHM 趋势称为亲和力曲线。

第六步是扩大验证时保持任务公平。Figure 5 汇总所有已测试模型相对于 within-library shuffle 的表达克隆信号，同时展示可靠 profile 的覆盖，避免把显著性当生物学机制。Figure 6 将同类工具的原生任务、已发表验证和实际共同任务测量分开。成熟方法按官方模型运行；没有运行、额外输入缺失、输出不同或代理实现都不能画成零分。本文的贡献要由真实数据中的解释与校准支撑，不能以“其他工具做不了”作为未经验证的前提。

图形也相应改变：Figure 1A 使用你确认原创的 GC 图，下面的细胞图采用紫蓝、淡绿和膜受体插画风格；Figure 2A/3A 按原文记录 reporter 机制、日期、分选、处理和样本来源；clone maps 放大可读家族标记并配同家族细胞实例。图版完成后从整条证据链复核：原文实验 → 正确个体/样本 → sequence membership → 捕获状态 → 对照 → 可支持的生物学句子。任何一步不成立，就降低主张或移出主线。

最后一次 Figure 1 精进从“展示四个计算方框”改为“追踪同一批细胞”。三个各六细胞的示例家族贯穿 RNA 状态、BCR 序列、家族成员、状态组成和克隆图；颜色表示状态，字母表示家族。读者因此能看见一个家族为什么跨越多个细胞状态，以及一个家族点为何代表分布。下面四张图像对应实际实验依据；打乱对照保持 RNA 位置和颜色，只改变 family 标签。环形状态组成是教学示意，实际 kernel profile 的定义保留在图注。

NP–OVA 的原生 benchmark 也改变了我们对方法定位的判断：普通 RNA 家族均值的 division-gate 读出好于 Threadfin 两种 profile，不能写成所有任务的最优方法。我们保留同上下文均值对照和所有模型结果；Benisse 的 30D MDS 仅保留约4.6%完整距离结构，因此性能改用完整 family kernel。这个修正保护了比较方法的原生信息，而没有改变或代理其模型。
