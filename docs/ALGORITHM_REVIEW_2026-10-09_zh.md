# Threadfin 算法复核与修订记录（2026-10-09）

结论：本次优先修复可复现的计算错误，并增加显式参考、采样不确定性和训练/查询分离能力。没有把用户 DOCX 中另一台机器的 302 家族比较或 KDE 原型当成已复现证据；没有因为新模型在某一指标有利就更换现有默认算法。

## 审查范围与主要判断

| 环节 | 代码 | 判断及处理 |
| --- | --- | --- |
| 输入、链选择 | api.py、io.py | 修复 AIRR 排序后重/轻链掩码未对齐；保留旧版读入接口差异。公开案例的独立 _airr_heavy 先筛重链，不受该错配影响 |
| 家族定义、SHM | clones.py、sequence.py、bcrgraph.py | 主路径为供者内 V/J/长度分层的阈值单链接；未知供者拒绝合并。修复 NumPy 全局比对漏罚前端 gap。SHM 不等于突变速率；indel、阈值、缺链仍需敏感性分析 |
| RNA 表征 | pp.py、expression.py | 原有共同 PCA/Harmony 属联合拟合；新增仅训练细胞拟合的 FrozenExpressionModel，支持真正留出小鼠的投影 |
| 均值/核特征 | profiles.py | 原始拟合的均值/核公式保留。修复带宽估计消耗随机数后重建 RFF 基底改变；存储 RNG 状态，恢复旧模型时匹配已保存特征；细胞、分组或坐标改变后要求重拟合 |
| 可靠性 | profiles.py | 细胞数阈值改为求解实际特征加权可靠性，替代不适用的 pooled-ICC 捷径；该值依赖随机效应模型，不能解释为无条件生物学可信概率 |
| programme 与标记 | programmes.py、stats.py | 修复零方差 null 下错误的 p=0；保留正常情况下既有计算。Gaussian split 是近似诊断，未复现整个选树/分辨率过程，撤去保证 FWER 控制的表述。标记基因重用 RNA，不能作为独立验证 |
| memory | dynamics.py | 配对 null 必须同供者、同目标采样层；不再缺候选时跨供者借用。过滤后重新检查配对数；校正距离分母非正时不报比值，bootstrap 比值不可识别时不制造有限区间 |
| 基因 ICC | heritability.py | 明确是克隆相关方差分量，不能单凭观察数据确立遗传或命运传递；增加缺失分层、无克隆、空基因集的边界检查 |
| 旧版图与统计 | core.py、integrate.py、metrics.py、migration.py、programs.py、specificity.py | 保留旧版接口；拒绝负权重，修正将 Laplacian 坐标称为 commute-time 的描述；细胞级 enrichment、序列匹配与 clone sharing 都有明确解释限制 |
| 模拟、显示、参数 | simulate.py、plotting.py、reclustering.py | 检查其与上游表格/参数的连接；二维图用于显示，不是统计检验空间。旧版 dense clone distances 仍为 O(C²)，大序列块近似候选也不等于完整同源性搜索 |

这份复核覆盖主要执行路径和数学假设，不代表对所有输入、实验设计和数值平台作了形式化证明。尤其是 programme 的选择后显著性、实际采样中的细胞相关性、跨供者泛化和直接 Clonotrace 比较，仍不能由常规单元测试解决。

## DOCX 六个方向如何落实

1. **采样感知的状态分布。** 新增可选的固定区域计数＋Dirichlet 收缩模型，提供原始比例、收缩比例、条件可信区间和独立计数区间。采用可检查的整数计数似然，未直接照搬未经验证的 KDE 原型。
2. **变化在哪里、对应哪些表达程序。** 输出区域差异与方向概率，并按“克隆内平均、克隆间等权”描述区域基因/模块。它们是解释工具，未冒充因果定位或独立差异表达发现。
3. **背景与评估隔离。** 参考克隆等权，背景排除自身家族；背景回退显式记录。新 RNA 模型将训练时的 HVG、缩放和 PCA 冻结。
4. **分开不同平滑/压缩因素。** 新模型不叠加图平滑、RFF 和克隆 PCA；连续显示采用固定多尺度混合，并区分显示核与计数不确定性。没有声称已完成所有因素的完整析因消融。
5. **独立 readout。** NP 7 只、RBD 10 只小鼠逐只留出，RNA 预处理也仅用训练鼠；保留 RNA mean、原始状态比例、收缩状态比例和捕获量基线。分选 gate 与测序 library 的混杂仍在。
6. **计算成本。** 查询可分块累计，模型可保存/读取；在相同输入、独立进程中记录时间与峰值 RSS。新模型在该基准上更省内存，但并不更快。

## 验证结果与适用范围

全部源表保存在 case_studies/results/algorithm_revision，包含不利结果。

- 固定参考模拟每场景 500 个家族，采样量 1/2/5/10/30/100。强异质性和纯状态家族会使收缩带偏；条件可信区间在纯状态边界覆盖为零。采用精确计数＋Bonferroni 的每家族全区域区间，测试中的最低覆盖率为 97.8%。这不是现实数据中无条件的覆盖保证。
- LARRY 参考与评估生物学条码完全分离：2,920 参考条码、216 评估条码、250 个 clone-day-well、20 次拆分。相对原始区域比例，固定 alpha=2 的 MSE 在 n=2/4/8 分别约降低 24.8%/11.3%/4.6%；仅参考数据校准出的 alpha=1 约降低 30.4%/16.2%/7.5%。RNA 坐标在拆分前共同拟合，故不是完整独立 RNA 流水线验证。
- 整鼠留出、n>=2 时，NP 的中位 MAE：RNA mean 0.2020、状态后验 0.2657；RBD 分别 0.2267、0.2459。不能宣称普遍优于简单 RNA 均值。RBD 的 n>=10 子集（222 家族、10 鼠）MAE 为 0.1738 对 RNA mean 的 0.1861；NP 同阈值为 80 家族、7 鼠。全部阈值、方法、鼠数和家族数见 density_reporter_summary.csv，不单独挑选有利子集。
- 50,000 细胞、5,000 克隆的独立进程基准：mean 约 0.061 s/291 MiB，kernel 6.12 s/594 MiB，新 density 8.34 s/290 MiB。不同方法输出和工作量不同；这些是该输入上的运行成本，不是生物学准确性排序。

## 论文影响与复现

原数据的 programme 稳定性、后验分配与 memory 依赖重建特征，必须重算。12 个数据集已全部重算，细胞和克隆身份、捕获量及可靠家族集合均一致；差异保存在 case_integration_audit.json。论文图文已切换到修订后的统计。例如 EBV 候选组从 3 变为 2，后期疟原虫从 7 变为 3；这反映下游特征重建修正，不是新发现的生物学阶段。重算包含新一轮浮点预处理，UMAP 坐标可整体转动，因此在确认克隆 ID 和资格一致后保留了原显示坐标，不能把坐标漂移写成生物学变化。

Figure 4 的 SPRING/Threadfin 对照解释分析单位的改变；本身不证明方法优越。额外加入 RNA mean + variance 基线，所有方法共用原来的训练/测试条码及内部 ridge 参数网格。原五种方法的 28,380 条预测与加入基线前完全一致。

最终验证：开发环境 198 项通过；安装 wheel 后 Python 3.10/3.11 各 198 项通过，3.12 为 197 项通过＋1 项既有 legacy-v3 重复性预期失败。三套环境的依赖检查、教程与 quickstart 均通过，25 个模块与源码/安装包逐字节一致。兼容性检查发现的旧 AnnData None 参数省略问题已修复。
